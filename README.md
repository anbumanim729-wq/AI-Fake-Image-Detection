# TruthLens - AI Fake Image Detection System

## Project Overview

TruthLens is an AI-powered Fake Image Detection System that identifies whether an uploaded image is Real or AI-generated/Fake using Deep Learning techniques. The system analyzes image patterns and provides a prediction result with confidence score through a web-based interface.

## Features

- Upload image for detection
- Classify images as REAL or FAKE
- AI-based image analysis
- Confidence score prediction
- User-friendly web interface
- Fast prediction results
